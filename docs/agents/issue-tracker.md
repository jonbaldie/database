# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues. Use `gh` for creation, reading, comments, labels, assignment, and closure. Pull requests are not a triage request surface.

## Wayfinding operations

- Maps carry `wayfinder:map`.
- Tickets are GitHub sub-issues carrying `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or `wayfinder:task`.
- Use native issue dependencies for blocking.
- The frontier consists of open, unblocked, unassigned child issues.
- Claim a ticket by assigning it before doing any work.
- Resolve it with a resolution comment, closure, and a context pointer under the map's "Decisions so far".
