# Governance

database uses maintainer-led governance for v0.1. The maintainer has final
decision authority for the project; there is no voting body or committee.

Contributors participate through ordinary GitHub issues and pull requests.
Maintainer approval and passing project checks are required to merge a pull
request. No prior issue approval, Contributor License Agreement, or Developer
Certificate of Origin sign-off is required.

This deliberately low-ceremony model may be reconsidered as the contributor
community grows.

v0.1 does not adopt a project-specific Contributor Covenant or standalone code
of conduct. That decision may be reconsidered if the contributor community
warrants it.
