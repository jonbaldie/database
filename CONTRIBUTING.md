# Contributing

Thank you for improving database. We welcome documentation, tests, bug fixes,
and feature contributions through ordinary GitHub pull requests.

## Before opening a pull request

- Follow the repository's `AGENTS.md` and the domain language in `CONTEXT.md`.
- Keep each pull request focused and explain its behaviour and verification.
- Run the relevant checks locally. `make quality` is the project quality gate.
- A prior issue is welcome when it helps discussion, but it is not required.

Pull requests need passing project checks and maintainer approval before merge.
The project is maintainer-led; see [GOVERNANCE.md](GOVERNANCE.md).

## Contribution terms

By intentionally submitting a contribution for inclusion, you agree that it is
provided under the [Apache License 2.0](LICENSE). The project does not require a
Contributor License Agreement or Developer Certificate of Origin sign-off.

Do not commit local tooling state or metadata, including `.beads/`.

## Coding standards.

Please read [CODING_STANDARDS.md](CODING_STANDARDS.md), understand it, and use
it whenever working with production code.
